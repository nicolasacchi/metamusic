# metamusic-worker

RunPod serverless worker for metamusic. It speaks the `mm.worker/1` contract (see
`docs/plans/2026-10-14-m3-generate.md`, C73/C83): it announces itself to the app through a signed start URL,
renders one take with YuE2, uploads the allowlisted artifacts through signed capability URLs and returns a
small JSON output.

Layout: `src/mmworker/` (package, JSON schemas under `schema/`), `tests/` (pytest, no torch, no network).

```
cd worker && uv run pytest --cov=mmworker --cov-fail-under=90
```

Modes (`python -m mmworker`, env `MODE`): `serverless`, `selftest`; `agent` exits 2 (arrives in M6).
The runtime dependency set contains no torch and no yue2: the image installs `yue2-infer` explicitly.

## Contract job and image

`contract/` holds the worker-contract job (`test_yue2_contract.py`): it runs against the commit pinned in
`contract/YUE2_COMMIT` with CPU torch, no weights, no GPU, and checks the yue2 signatures, the artifact file set
(`testdata/artifacts.json`), the Hugging Face allowlist, offline behaviour and agreement with the Go batch
validator (`testdata/batch_cases.*`, regenerated by `go test ./internal/engine/yue2 -run
TestWriteBatchContractCases -update`).

```
uv venv /tmp/contract-venv && uv pip install --python /tmp/contract-venv/bin/python \
  --extra-index-url https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match \
  "torch==2.10.0" "yue2-infer @ git+https://github.com/multimodal-art-projection/YuE@$(cat worker/contract/YUE2_COMMIT)" \
  pytest pytest-timeout numpy
PYTHONPATH=worker/src /tmp/contract-venv/bin/python -m pytest worker/contract -q
docker build -f worker/Dockerfile --build-arg YUE2_COMMIT=$(cat worker/contract/YUE2_COMMIT) worker/
```
