# M0 — Skeleton, Privacy-First Public Repo, CI — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this
> plan task-by-task (TDD per task, review between tasks). Read `CLAUDE.md` first.

**Goal:** a runnable, fully tested skeleton where one operation registry serves REST + MCP + the SPA,
humans authenticate via proxy headers or a local password, agents via personal access tokens, and CI
+ local hooks keep the public repo free of private data.

**Architecture:** `cmd/metamusic` (subcommands) → `internal/httpserver` composes: auth middleware →
{`/api/*`, `/human/api/*` → Huma API on an inner mux; `/mcp` → go-sdk streamable handler whose tools
dispatch in-process into the inner mux; `/healthz`; `/auth/*` (local mode); SPA static + fallback}.
SQLite via `internal/store`. Svelte 5 SPA in `web/` embedded with `go:embed`.

**Tech stack:** Go 1.27, Huma v2 (humago adapter on `http.ServeMux`), `github.com/modelcontextprotocol/go-sdk`,
`modernc.org/sqlite`, `golang.org/x/crypto/argon2`, `github.com/google/go-cmp`; Svelte 5, Vite, Bun,
TypeScript, openapi-typescript, openapi-fetch, ESLint (flat) + eslint-plugin-svelte, Playwright.

Pin every dependency to the latest stable release at implementation time (verify with
`go list -m -versions`, `bun info <pkg>` and context7). Record chosen versions in the task report.

### C3. Principals & auth (`internal/auth`)

> **M4a amendment (B1):** `Principal` gains `Client`; `Via` gains `oauth` and `subsonic`; `Middleware(cfg, sec, Verifiers{…})` replaces the positional verifiers; row 1b (a connector's JWT bearer on `/mcp` only) is added and `/sw.js` is public (M4a C104).

```go

const (KindAnonymous Kind = "anonymous"; KindHuman = "human"; KindAgent = "agent")

    ID      string   // human: username; agent: token id

type PathClass int // ClassUI, ClassMachine, ClassPublic

// ClassMachine: /mcp, /mcp/*, /rest/*, /media/*, /worker/*, /.well-known/*, /oauth/token, /oauth/register, /oauth/revoke
// ClassUI:      everything else (/, SPA routes, /api/*, /human/*)

func Middleware(cfg config.Config, sec config.Secrets, tokens TokenVerifier, sessions SessionVerifier) func(http.Handler) http.Handler
```
Resolution order (implement exactly; table-test every row):

| # | Condition | Result |
|---|---|---|
| 1 | `Authorization` header present | Only bearer: `Bearer mmp_…` verified via `TokenVerifier` ⇒ agent principal with token scopes; malformed/unknown/revoked ⇒ **401** problem `UNAUTHENTICATED` (`WWW-Authenticate: Bearer`). Remote-*, X-MM-Edge, cookies ignored. |
| 2 | ClassPublic | anonymous, pass through |
| 3 | ClassMachine and no bearer | anonymous (handlers decide; `/mcp` returns 401 with `WWW-Authenticate: Bearer resource_metadata="<PublicURL>/.well-known/oauth-protected-resource/mcp"`) |
| 4 | ClassUI, mode=proxy | human iff ALL: `RemoteAddr` IP ∈ TrustedProxies; `X-MM-Edge` present exactly once and constant-time-equal to `sec.EdgeSecret`; `Remote-User` present exactly once, no comma, ∈ TrustedUsers. Else anonymous. |
| 5 | ClassUI, mode=local | human iff valid `mm_session` cookie (HMAC lookup, not expired). Remote-* never read. Else anonymous. |

Anonymous on ClassUI: `/api/*` and `/human/api/*` ⇒ 401 problem `UNAUTHENTICATED`; HTML routes ⇒
local mode: 303 to `/auth/login`; proxy mode: 401 plain page "Not authenticated".
Wrap unsafe methods with `http.NewCrossOriginProtection()` (Go ≥1.25) for cookie/proxy principals.

**C3 addendum (as implemented in A2; other lanes code against this):**
- Cross-origin refusal is `403` problem code `CROSS_ORIGIN`. It applies to cookie/proxy principals in the
  middleware and to `POST /auth/login` and `POST /auth/logout` (wrapped inside `LocalAuth.Handler`). It
  refuses `same-site` as well as `cross-site` unsafe requests, and foreign `Origin` without `Sec-Fetch-Site`.
- **M1 (M1-B1):** every hand-written problem response outside Huma goes through the leaf package
  `internal/problem` (`problem.Write(w, status, code, msg, details)`): `auth.writeProblem` and the
  `LocalAuth.Handler` CROSS_ORIGIN deny handler, `httpserver.writeProblem` (formerly `problem`, which
  concatenated strings without escaping), the `api.notFound` 404/405 writer and the `mcpgen.problemWriter`
  transport-error rewriter. `api.writeProblem(huma.Context, *Problem)` and `mcpgen.problemResult` stay.
- Infrastructure failures in token/session verification (anything other than `ErrInvalidToken` /
  `ErrInvalidSession`) return `500` problem code `INTERNAL`; they are logged via slog without secrets.
- The `Bearer` scheme is matched case-insensitively. Dot-segment (`..`) paths classify as `ClassUI`.
- Constructors: `NewTokenStore(st *store.Store, key []byte) *TokenStore`,
  `NewLocalAuth(st *store.Store, key []byte, publicURL string) *LocalAuth` (`FailDelay` field, default 1s).
- `TokenStore`: `Create(ctx, name, []Scope) (plaintext, id string, err)` (validates: non-empty name, >=1 scope,
  known and unique scopes, else `ErrInvalidScope`), `Verify`, `List(ctx) ([]TokenInfo, error)`, `Revoke(ctx, id) error`.
  `TokenInfo{ID,Name,Prefix,Scopes,CreatedAt,LastUsedAt,RevokedAt}` (no hash). IDs are UUIDv7.
- `LocalAuth`: `SetPassword(ctx, username, pw) error` (also deletes all sessions), `Login(ctx, username, pw) (cookieValue string, err error)`,
  `VerifySession(ctx, cookieValue) (Principal, error)`, `Logout(ctx, cookieValue) error`, `Handler() http.Handler`.
  Argon2id work is bounded to 2 concurrent hashes; when saturated and ctx ends, `ErrBusy` (login handler: 503).
- Session cookie `mm_session` (`SessionCookie`; named `__Host-mm_session` when PublicURL is https, so sibling hosts cannot plant or shadow it; with duplicates the first valid one wins): HttpOnly, SameSite=Lax, Secure iff PublicURL is https,
  Max-Age 12h. The middleware re-issues it on every authenticated local request (sliding); the server-side
  expiry slides at most every 5 minutes.
- Sentinels: `ErrInvalidToken`, `ErrNotFound`, `ErrInvalidScope`, `ErrBadCredentials`, `ErrInvalidSession`, `ErrBusy`, `ErrInvalidPassword` (SetPassword rejects blank/whitespace username or password), `ErrWeakPassword` (password under 12 characters).
  Failed logins are serialised on a process-wide mutex with a growing delay (`FailDelay` x1..x32); at most 16 login attempts are in flight, extra ones get 503 at once.
  A successful `POST /auth/login` also invalidates the `mm_session` the client presented (rotation).
  `TokenStore.Verify` writes `last_used_at` only when NULL or older than 60s, under a 250ms bounded ctx.
- The login page sets `frame-ancestors 'none'` and `X-Frame-Options: DENY` itself.

Tokens (`internal/auth/tokens.go`): format `mmp_` + 52 chars base32 (no padding, lowercase) of 32
random bytes. Store `prefix` (first 8 chars after `mmp_`) and `hmac_hash = hex(HMAC-SHA256(sec.Key, token))`.
```go
type TokenStore struct{ /* *store.Store, key */ }
func (t *TokenStore) Create(ctx, name string, scopes []Scope) (plaintext string, id string, err error)
func (t *TokenStore) Verify(ctx, plaintext string) (Principal, error) // updates last_used_at (best effort, async-safe)
func (t *TokenStore) List(ctx) ([]TokenInfo, error)                    // never returns hashes
func (t *TokenStore) Revoke(ctx, id string) error
```
**C3 addendum (M2a-B1):** `NewTokenStore(st, key, now func() time.Time)` takes the clock (nil => `time.Now`),
`(*TokenStore).Get(ctx, id) (TokenInfo, error)` (`ErrNotFound`) is new, `(*LocalAuth).UseClock(now)` replaces
the session clock, and `Principal` gains `KindDevice`, `KindSystem`, `StepUpAt`, `Key()`, `ActsAsHuman()` and
the `CLI` principal. See the M2a plan, C26.
**C3 addendum (M2a-B9):** rows 6-7 of the C26 table are implemented. In `Middleware`, a UI-class request that rows 4/5
did not authenticate and whose path is not under `/human/` reads `mm_dev` (first valid of at most four); a valid
cookie is a device principal (scopes `read,write`, `Via` `device`, `CrossOriginProtection` applies) and is re-issued
only when the server-side expiry slid. A cookie that was read and rejected is cleared; HTML routes then answer 303
`/start?expired=1` in both modes, API routes keep the 401 problem. Cookies under `/human/` and on machine or public
paths are never read, hence never cleared. `Classify` makes `/start`, `/pair`, `/pair.js` and `/auth/pair` public.
Local mode step-up: `LocalAuth.StepUp(ctx, cookie, password)`, `VerifySession` fills `Principal.StepUpAt`, and a local
human request under `/human/` whose last confirmation is older than 10 minutes (by the verifier's own clock, via the
optional `StepUpFresh(Principal) bool`) gets 403 `STEP_UP_REQUIRED` (`/human/api/`) or 303 `/auth/step-up?next=<path>`;
`LocalAuth.Handler()` serves `GET`/`POST /auth/step-up` (the redirect target must start with `/human/` and contain no
`//`, backslash or control character, else `/human/tokens`). Proxy mode has no `/auth/step-up` (404).
Local human auth (`internal/auth/local.go`): argon2id (`time=3, memory=64MiB, threads=2, keyLen=32`,
PHC-format string); `SetPassword(username, pw)`; `Login(username, pw) (cookieValue)`; session cookie
`mm_session` HttpOnly, Secure when PublicURL is https, SameSite=Lax, Path=/, 12h sliding expiry;
stored as HMAC hash. `/auth/login` GET serves a minimal HTML form, POST validates (constant-time,
generic error, 1s delay on failure); `/auth/logout` POST deletes the session.

### C5. MCP adapter (`internal/mcpgen`)

```go
func NewServer(api huma.API, inner http.Handler, version string) (*mcp.Server, error)
func Handler(srv *mcp.Server) http.Handler // StreamableHTTPHandler{Stateless: true, JSONResponse: true}
```
- Walk `api.OpenAPI()`; for each op: `x-mm.mcp == "tool"` ⇒ tool named OperationID; `"generic"` ⇒
  reachable only via `describe_operation(operation_id)` / `call_operation(operation_id, arguments)`
  (these two are always registered); `exclude:*` ⇒ unreachable.
- Tool description = summary + "\n\n" + description. Annotations: GET ⇒ `readOnlyHint: true`;
  `x-mm.cost == "spend"` ⇒ `openWorldHint: true`.
- Input schema = object merging path params + query params + header params (renamed to snake_case,
  e.g. `Idempotency-Key` → `idempotency_key`) + body properties flattened. If any name collides,
  nest the entire body under property `body` for that tool. Inline `$ref`s into `$defs`.
- Output schema = the 2xx JSON response schema (inlined).
- Handler: build an `*http.Request` (method, path with params substituted & escaped, query,
  headers, JSON body) whose context carries the **already-resolved principal** (from the MCP HTTP
  request context, via the go-sdk request/extra API — verify how the request context propagates in
  stateless mode and test it); serve it on `inner` (the Huma mux, NOT the outer auth chain) with
  an `httptest.ResponseRecorder`; return `StructuredContent` = parsed JSON body; status ≥ 400 ⇒
  `IsError: true` with the same problem JSON as text content.
- `/mcp` requires an agent principal (bearer). Anonymous ⇒ 401 + `WWW-Authenticate` (C3 row 3).
- Addenda (B1 review): `Handler` sets `DisableLocalhostProtection: true` (bearer-only auth makes DNS
  rebinding moot; the guard would 403 reverse-proxied loopback deployments). `openWorldHint` is set
  explicitly (`false` unless cost is `spend`). Array query params honour the OpenAPI `explode` flag
  (comma-joined when false, repeated keys when true); JSON null for an optional param means absent;
  an optional request body is nested under `body` (never flattened) so it can be omitted.
- **C5 addendum (M2a-B2b, C30):** `dispatch(ctx, inner, spec, args, origin)` also receives the transport
  mark (`mcp`, or `stdio`) and the client label and stores them with `reqinfo`. The label is the HTTP
  `User-Agent` from `CallToolRequest.Extra.Header` (the stateless handler synthesizes initialize params
  without `clientInfo`), else the initialized session's `clientInfo` as `name/version` (stdio, in-memory).
  `inner` is the **gated** handler. For `x-mm.idempotency == "create"` operations the `idempotency_key`
  argument is optional (`toolSpec.Params[...].Required == false`, not in the input schema's `required`,
  with the C30 description); when absent, `dispatch` derives `idem.DerivedKey(principal.Key(), op, args)`
  before the required-parameter check, passes it as the header and marks the context with
  `idem.WithDerived`. `describe_operation` adds `idempotency`, `rate` and `secret_fields` when set.
  `NewStdioServer(a, gated, StdioOptions{Principal, Version})` registers the same tools and resolves the
  principal before every tool call (`UNAUTHENTICATED` for `auth.ErrInvalidToken`, else `INTERNAL`).

`Content-Security-Policy: default-src 'self'; img-src 'self' data: blob:; media-src 'self' blob:;
connect-src 'self'; style-src 'self' 'unsafe-inline'; frame-ancestors 'none'`, `X-Content-Type-Options: nosniff`,
`Referrer-Policy: same-origin`.

**C6 addendum (M1-B1):** the 404/401 problem bodies in `httpserver` are written by `internal/problem`
(JSON-encoded, so messages with quotes or newlines stay valid JSON).

**C6 addendum (M1-B4):** `Options` gains `Library *library.Service`, `Signer *serve.Signer`,
`Probe *serve.Object`, `Media http.Handler` and `Now func() time.Time`. `New` passes `Library`, `Signer`,
`Probe` and `Now` into the `api.Deps` it builds and mounts `Media` at `/media/` on the outer mux before the
SPA catch-all; a nil `Media` answers 404 problem `NOT_FOUND`, like a nil `MCP`.

**C6 addendum (M2a-B4a):** `Options` gains the M2a services `Judgments`, `Drafts`, `Playlists`, `Exports`, `Backups`,
`Context`, `Listening`, `Devices auth.DeviceVerifier` (a nil *interface* disables device auth), `DeviceStore
*auth.DeviceStore` (a nil pointer is converted to a nil verifier) and `Notify`; `auth.Middleware` takes a fifth
`DeviceVerifier` argument (rows 6-7 of the C26 table arrive with M2a-B9).

**C6 addendum (M2a-B2a):** `Options` gains `Audit *audit.Store`, `Idem *idem.Store`, `Limiter *ratelimit.Limiter`
and `NewID func() string`; `New` wraps the inner mux in `gate.New` (audit recorder, authorize, rate limit,
idempotency) and hands the **gated** handler to `/api/`, `/human/api/` and `MCPFactory`. Nil gate
dependencies are replaced by defaults built from `Store`, `Now` and `NewID`, so the gate is never skipped;
`app.Build` supplies one shared set. The served-operation recorder (E2E) wraps the gate. With `Cfg.E2E`
the outer handler is also wrapped by a leak scanner: every response's headers, and bodies outside `/media/`
(through a window that catches canaries split across writes), are scanned for the static canaries
(`secret_key` raw/hex/base64, `edge_secret`, `ntfy_token`); `GET /__e2e/leaks` lists
`{path, method, kind, where}` (never a value). Without E2E, `/__e2e/*` answers 404 `NOT_FOUND`.

### C9. Metrics wrapper (`scripts/loop`)
`scripts/loop <target> -- <command…>` runs the command, streams output, and appends one JSON line to
`$MM_METRICS_FILE` (default: `<git-common-dir>/../metrics/loop.jsonl`, shared across worktrees):

(`additionalProperties: false`). Exception: only allowlisted build/test targets are wrapped; `hooks`, `tools`, `dev`, `metrics` and `clean` run unwrapped. `metrics/loop.jsonl` is gitignored; `make metrics` renders
`metrics/REPORT.md` (committed per milestone).
