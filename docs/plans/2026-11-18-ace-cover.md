# ACE-Step cover (post-E2 follow-up)

Status: built, unverified. `features.verified.json` does not list `cover`, so every cover request is refused with
`ENGINE_CAPABILITY` until the operator runs the canary case `cover` and flips the flag in a separate PR.

## What it is

Audio-to-audio restyle of a whole take (usually a YuE2 take) from a new caption, keeping its structure and melody, with a
strength control. It produces a new track (not an artifact, unlike stems), with the parent edge and operator `cover_restyle`.

## Upstream facts (ACE-Step 1.5 at the pinned commit)

- `cover` is listed for the turbo and the base DiT; its instruction is "Generate audio semantic tokens based on the given
  conditions:". The LM is skipped for it, and the length comes from the source audio (no duration is sent).
- `audio_cover_strength` is a float 0..1 (1.0 stays closest to the source, about 0.2 is a style transfer). `cover_noise_strength`
  is undocumented and stays at its default; `cover-nofsq` and `audio_codes` are never used.
- Whether the turbo checkpoint quantises the source into codes as intended is proven only by the canary.

## Decisions

- Class turbo (8 steps, no guidance, existing RTF row); cover never teaches the RTF.
- Recipe field `cover_strength_milli` (integer 0..1000, no float in recipes), required (no hidden default in the recipe hash). The
  API item carries `edit.strength` 0..1 (rounded to 0.001); the UI preselects 0.5.
- Item mode `cover` (`parent_track_id`, `patch.style` required, `patch.lyrics` optional, `edit.strength`, `n_seeds` or `seeds`).
  Any parent take with a master is allowed; a YuE2 parent is labelled `cross_engine_edit`.
- Part tag E2b (capability `cover`); the SPA shows a "Restyle" action when the engine caps list the mode.
- The worker contract gains `cover_strength_milli` and a cover branch; this needs a new worker image.

## Order of shipping

Merge, CI builds the image, the digest is committed by hand, the endpoint is redeployed, the operator runs the canary and
listens, then a separate PR adds `cover` to `features.verified.json`.
