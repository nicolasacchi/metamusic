**Goal.** Compose before paying for audio. The Desk turns YuE2's ABC score into something the operator and agents can read, edit bar
by bar, hear for free and only then render: **plan → audition → render**. Plans come from three places: a cheap **plan job** on the GPU
that drafts scores for many seeds (`plan_seeds`), the score that **every existing take** with `cot` full or melody already carries
(free), and **edits** of either (free). The **audition** is the T1b score renderer: a deterministic CPU render of the score through
fluidsynth and a committed-licence General MIDI soundfont, so a plan is heard before any GPU render. **Render** is an ordinary
estimate (`render_plan`) that renders the plan's score text through YuE2's existing render-from-score path. T1b also makes
`create_transform` kind `score_render` work as T1 specified, producing score-faithful Takes on request.

**Architecture (one paragraph).** One ABC toolkit, `internal/score/abc`, parses YuE2's dialect and standard ABC into a syntax tree with
the byte span of every bar (for edits and for clicking a bar in the notation) and into note events (`internal/score`), checks
structural invariants and applies three bar-level edits. The T1b pipeline turns a score into an SMF (`internal/score/smf`), renders it
with fluidsynth (`internal/score/synth`, a separate LGPL process run through `internal/mediatool`), decodes the output exactly and
hands it to T1's render child, whose only job for this kind is T1's safety finish, so the result obeys T1's determinism contract
(`pcm_sha256`). The Desk (`internal/desk`, one additive migration) stores immutable plans and their files under `plans/`, keeps
per-rater verdicts, and keeps auditions as a content-addressed MP3 cache under `derived/` served through the existing media resolver
chain. Two generation modes plug into the existing `estimate_generation` / `create_generation` pair: `plan_seeds` (job kind `plan`,
needs `[plan, v2]`, G1's gate) and `render_plan` (job kind `generate`, plain `mm.worker/1`). The worker gains one stage, `plan`
(`pipe.plan()` per seed, bundles uploaded as `plan-NN.tar`), shipped in a worker wave. The SPA gains `/desk` with abcjs notation, a bar
editor and an audition player on the shared `AudioContext`.

**Plan decisions:**

- **D-DESK-1** The Desk works on **plans**: immutable candidate scores with a seed, a `cot` and a base request. Three sources: `job` (a
  plan job's seed), `take` (an existing take's `score.abc`), `edit` (bar-level edits of another plan). Editing never changes a plan; it
  creates a child plan. A plan is never a Take and never enters the library views.
- **D-DESK-2** `render_plan` renders the plan's **score text**: the take's recipe is the plan's base request with `abc` = the score bytes,
  the plan's `cot` and seed (YuE2's documented render-from-score path, already exercised by the canary main case). It travels as plain
  `mm.worker/1` and needs no capability. YuE2 re-tokenises the text, so the take follows the auditioned composition but is not
  guaranteed bit-identical to a one-shot render of that seed; the exact-token path (`SymbolicPlan.load`, G1 capability `attach`) is
  **deferred** until a measured need. Extra seeds of the same score are allowed (n ≤ 4): "same score, new performance".
- **D-DESK-3** `plan_seeds` creates jobs of kind `plan` (needs `[plan, v2]` by `jobspec.Needs`), at most `seedsPerJob(A)` seeds per
  job (C360.5); operator `plan_seeds` is a **job** operator, never an Operator Ledger operator (a plan job makes no take). The job's
  `recipe_id` is the parent's recipe when the item has no patch and a parent base, else a new recipe of the planned content (G1 D-G1-6).
- **D-DESK-4** Quotes use main's phase model unchanged. A plan job is `TakeIn{AudioS: n·A, RTFMilli: spend.PlanMilli, LoadS:
  spend.LoadS}`; a `render_plan` take is quoted like any render with `Full = cotIsFull(request)` (conservative: a `cot=full` request with
  an `abc` is charged the planning phase although YuE2 should skip it) until the `plan-render` canary measures the phase; then the
  constant `generation.DeskRenderSkipsPlan` flips to `true` in a one-line PR the operator approves. No `spend.TakeIn` field is added.
- **D-DESK-5** **Economics, honest:** plan-first is not cheaper than blind renders at main's quote (about 8 % dearer in expected
  worker-seconds for "8 plans + 2 renders" against "4 blind renders" at the default 200 s attempt overhead; break-even at about 116 s).
  It buys **control** (the composition is chosen and edited before audio is paid for) and **breadth** (about 1.85 times as many
  candidates heard per worker-second). The spend-free half (plans from takes, edits, auditions) costs no GPU at all. The design's
  acceptance item becomes "measured and reported" (C364.4), not a gate.
- **D-DESK-6** An **audition** is a Desk preview, not a Take: a content-addressed MP3 under `derived/auditions/`, keyed by everything
  that determines its PCM, never backed up (rebuilt on demand), served through the media resolver chain like voice notes. It is rendered
  synchronously (≤ 90 s) through the T1b pipeline under the transform runner's slot. "Keep as Take" is an explicit `create_transform`
  kind `score_render`.
- **D-DESK-7** T1b runs the pure-Go steps (parse, events, SMF) and fluidsynth **in the parent** (fluidsynth through `mediatool` in group
  mode with a minimal environment), decodes its output exactly to the child's input file, and the **render child** runs kind
  `score_render` = identity plus T1's common safety finish. The child keeps importing only the standard library and `internal/dsp/...`
  (`TestDspRun_Imports` bans `os/exec`), and `pcm_sha256` stays the oracle.
- **D-DESK-8** fluidsynth argv (amends T1 C208.5): `fluidsynth -q -ni -o synth.cpu-cores=1 -g <gain> -r 48000 -R 0 -C 0 -T wav -O float
  -F <out.wav> <soundfont> <score.mid>`. `-O float` removes an integer quantisation before ours; one core removes thread scheduling from
  the synthesis. `TestFluidsynth_Argv` is the golden.
- **D-DESK-9** Soundfont: **FluidR3_GM** (General MIDI, MIT licence), from Debian's `fluid-soundfont-gm` 3.1-5.3 package with two
  pins (package and extracted file), baked into the app image with its licence text and a THIRD_PARTY_NOTICES entry; never committed to
  git; fetched for development by `scripts/tools.sh soundfont` (opt-in, like `flac`); CI tests use a generated single-preset SF2.
- **D-DESK-10** One ABC toolkit (`internal/score/abc`) for the program, with two dialects (`yue2` carries an accidental across octaves to
  the bar line, `standard` follows ABC 2.1). Plans from YuE2 are `yue2`. `yue2.ParseScore` stays the timing source of `scores` rows and
  of `sections` with source `plan`; agreement is pinned by tests, not by replacing it.
- **D-DESK-11** YuE2 `cot=full` plans are chord-annotated; auditions render chord symbols as **block chords** (`chords: block`, a third
  voice). The T1 API keeps `none` as its default so `score_render` stays score-literal unless asked.
- **D-DESK-12** Desk edits keep the structure: same voices, same bar count per voice, same headers (tempo only through `set_tempo`), same
  sections; only edited bars must have a meter-length duration. Structural edits (adding or removing bars) are out of v1.
- **D-DESK-13** Song PR bar edits (`replace_bars`): at most 16 bars per patch, one voice per op, only inside the scoped sections' bar
  ranges of an aligned base score, invariants as D-DESK-12; operator `abc_edit` alone, `multi_edit` with lyrics or style. This amends
  the 2026-11-03 decision "no ABC bar edits in M5" and needs the operator's confirmation (operator input 8).
- **D-DESK-14** U1: every Desk operation is `mcp: generic`; Owner and Editors read and write plans and auditions; Listeners reach none;
  plan verdicts are Owner-only for people (D-G1-16: curation signals) and the critic row for agents. No Desk response carries money, so
  no shape rules are needed.
- **D-DESK-15** abcjs reads standard ABC. When a YuE2-dialect score reads differently under the standard rule, the server also returns a
  **display normalisation** (explicit accidentals) with its own bar spans; the stored score never changes.
- **D-DESK-16** A library reader for a take's score text, `library.(*Service).ScoreABC`, is added and wired into `trackctx`
  (`get_track_context include=score` answers `abc: null` today because `UseScoreABC` is never called outside tests). Transform's
  key-ladder hook (`transform.Options.ScoreABC`) stays unwired on purpose: T1 keeps estimates database-only (D-T1-6,
  `transform.go:58-60`).
- **D-DESK-17** abcjs (MIT, no dependencies) is pinned exactly and lazy-loaded by the Desk routes; notation only. Its synth is never
  used; playback is always the T1b audition.
- **D-DESK-18** Limits: a plan score ≤ 64 KiB (YuE2's 4 096-token ABC cap keeps real plans far below), a plan bundle ≤ 2 MiB, an audition

## Economics (honest)

Main's quote (`internal/spend/quote.go:47-149`): generation `gen = LoadS + ⌈(rtf + plan) × audio / 1000⌉` with `LoadS` 10, `rtf` 680,
`plan` = `PlanMilli` 220 for `cot=full` only; `expected_s = gen + 10`; `timeout_s = min(MaxRuntimeS, ⌈1.6·gen⌉ + 80)`; take reserve
`timeout_s + KillSlackS`; one attempt overhead `ColdStartS + IdleS` per batch; ceiling = Σ max + retry allowance `min(n, workers_max) ×
max`. Defaults: `MaxRuntimeS` 900, `KillSlackS` 15, `ColdStartS` 180, `IdleS` 20 (overhead O = 200 s), `workers_max` 2. Song A = 200 s.

| Unit (A = 200 s) | gen | expected_s | timeout_s | max (incl. O) |
|---|---|---|---|---|
| blind full render (`cot=full`, no abc) | 190 | 200 | 384 | 599 |
| `render_plan` take, conservative (`Full` true until measured) | 190 | 200 | 384 | 599 |
| `render_plan` take after the flip (`Full` false) | 146 | 156 | 314 | 529 |
| plan job, 8 seeds (`AudioS` 1 600, `RTFMilli` 220) | 362 | 372 | 660 | 875 |

| Flow | expected worker-seconds | ceiling worker-seconds | candidates heard |
|---|---|---|---|
| B: 4 blind full renders (one batch) | 1 000 | 3 594 | 4 (real audio) |
| A: 8 plans + 2 renders from plans, after the flip | 1 084 | 3 866 | 8 (auditions) then 2 |
| A, conservative quote | 1 172 | 4 146 | 8 then 2 |
| A1: 8 plans + 1 render, after the flip | 928 | 2 808 | 8 then 1 |
| Spend-free Desk: plan from an existing take, edits, auditions, 1 render (after the flip; 400 and 1 198 before) | 356 | 1 058 | any number of auditions |

Reading: A beats B only if O < 116 s; per heard candidate A costs 135 worker-seconds against B's 250; an audition costs CPU seconds
only. Real spend follows `expected`, not the ceiling; the private appendix converts these to money at the live price.

### C352. ABC toolkit (`internal/score/abc`; merges T1 C208.2–3 and M5 draft C94)

1. **Syntax layer.**
   ```go
   type Dialect string // "yue2" | "standard"
   type Options struct{ Dialect Dialect; DefaultBPM float64 /* 120 when Q: is absent */ }
   type Rat struct{ Num, Den int64 } // reduced, Den > 0
   type Tune struct{ Header Header; Voices []Voice; Sections []Section; Features []Feature; Warnings []Warning; Src []byte }
   type Header struct{ Meter, Unit Rat; Tempo *Tempo; Key Key; Fields map[string]string; BodyStart int }
   type Voice struct{ ID, Name string; Program *int; Bars []Bar }
   type Bar struct{ Index, Line int; Start, End int /* byte span of the content, bar lines excluded */; Notes []Note; Chords []Chord; Length Rat }
   type Note struct{ Pitch int /* MIDI, -1 rest */; At, Dur Rat; Tie bool; Start, End int }
   type Chord struct{ Root int; Quality, Raw string; At Rat }
   type Section struct{ Label, Kind string; StartBar, Bars int } // "% verse" comments, yue2.sectionKind rules
   type Feature struct{ Code string; Line int }                  // repeat, volta, inline_field (overlay `&` is a SyntaxError, T1)
   type SyntaxError struct{ Line, Col int; Rule, Msg string }
   func Parse(src []byte, o Options) (*Tune, error)               // ≤ transform.MaxScoreBytes; never panics (fuzzed)
   type TimedNote struct{ Bar int; Start, Dur Rat /* whole notes from the tune start, source order, repeats not expanded */; MIDI int /* -1 rest */ }
   func (t *Tune) Notes(voice int) []TimedNote                    // key signature and dialect accidentals applied
   func (t *Tune) SecondsPerBar() (float64, bool)                 // false when untimed (no Q:, or a timing-relevant feature)
   ```
   **Interface for the Ears track** (its C336.2, score adherence): `Parse(src, Options{Dialect: "yue2"})`, `t.Header.Meter`,
   `t.Header.Tempo`, `t.Header.Key`, `t.Notes(i)`, `t.Sections`, `t.SecondsPerBar()`. These names are frozen by DESK-A1; Ears amends
   its list to them (its plan already says it will).
   Supported syntax, unsupported rules and the velocity rule are T1 C208.2 verbatim. YuE2 output is often irregular: an irregular bar
   length, an unknown `%%` line or a decoration is a **warning**, never an error.
   **As built (DESK-A1; the code is the contract where it differs above).** Additions to the frozen names, none renamed:
   `Header` also has `MeterNum, MeterDen` (the written meter; `Meter` is the reduced bar length, so 6/8 is 3/4 there); `Tempo` is
   `{Unit Rat; BPM float64; Raw string}` (nil when `Q:` is absent or unsupported; a bare `Q:120` is a quarter-note tempo); `Key` is
   `{Raw, Tonic, Mode string; Sharps int; Accidentals [7]int}`; `Voice` also has `Channel *int` (`%%MIDI channel n`, 1-based, 10 refused);
   `Bar` also has `Left, Right string`, `RepeatStart, RepeatEnd bool`, `Volta int` and `Changes []Change` (inline or line-form `M:`/`Q:`
   with their offset in the bar); `Feature` also has `Detail` (the field letter for `inline_field`); `Warning` is `score.Warning`.
   `Tune.Notes` returns every note and rest in source order with `Start` counted from the sum of the preceding bar lengths. For the Ears
   track: `Tune.BeatUnit()` (the `Q:` unit, else a quarter) and `Tune.BeatNotes(voice) []BeatNote{Bar, MIDI, Onset, Dur}` give onsets
   and durations in beats. Bars: a multi-bar rest `Z4` yields four bars sharing one span; a voice switch closes the open bar of the
   voice left (as `yue2.ParseScore`); a voice's bars are in source order and `Tune.Voices` is ordered by first music. Chord symbols
   accept a slash bass (`Am/E`, the bass is not sounded) and the aliases `min`, `M7`, `-`, `+`, `sus`. Parse refuses with
   `too_large`, `bad_dialect`, `too_many_events` (more than 200 000 bars, or repeats expanding past that) and `bad_length` (a duration
   whose exact fraction overflows int64); lengths are limited to numerators and denominators of at most 128. `Score` returns
   `too_many_voices` when the voices do not fit the 15 non-percussion channels, `too_long` past 20 minutes. `SecondsPerBar` is
   false for a repeat, volta, inline or line-form `M:`/`Q:`, an inline `[V:]`, a section with no bars, or no usable `Q:`.
2. **Dialects** (D-T1-15, D-DESK-10): table `TestABC_Accidentals` of T1 C208.3 verbatim (`K:C ^F f |` ⇒ standard `[66, 77]`, yue2 `[66,
   78]`; the next bar resets both; key signatures apply in both).
3. **Events.** `func (t *Tune) Score(o EventOptions) (*score.Score, error)` with `EventOptions{Chords ChordMode /* none | block */;
   Programs map[string]int}`: repeats and first/second endings expanded, tuplets, broken rhythm, ties, inline tempo and meter changes
   (T1 C208.2). Programs: `%%MIDI program n` wins; else `EventOptions.Programs[voice id]`; else 0. T1's `score_render` passes no map
   (T1 cut the voice-name heuristic for score renders); the Desk audition passes `desk.AuditionPrograms` (a voice whose id or name
   matches `^1$|vocal|voice|melody` gets 53, any other 0). `block` chords: each chord symbol (roots `A`–`G` with `#`/`b`; qualities maj, m, 7, maj7, m7, dim, dim7, aug, sus2, sus4, 6,
   m6, 9, add9; anything else ⇒ warning `chord_unknown` and no chord) sounds as a close-position chord with its root in 48..59, from its
   position until the next symbol or the bar end, on its own voice `chords`, program 48, velocity 60.
4. **Invariants.** `func CheckInvariants(base, edited *Tune, a Allow) []Violation` with `Allow{Tempo bool}` and codes `voices_changed`,
   `bar_count_changed` (per voice), `bar_length` (an **edited** bar whose length is not the meter, unless it is that voice's first or
   last bar and equals the original bar's length), `header_changed` (`M:`, `L:`, `K:`, and `Q:` unless allowed), `sections_changed`
   (labels or start bars), `unsupported_feature` (an edited bar contains a repeat, volta or inline field).
5. **Edits.** `func Edit(src []byte, t *Tune, ops []Op, o Options) (out []byte, edited *Tune, v []Violation, err error)`:
   - `replace_bars {voice, bar_from, bar_to, abc}` — `abc` holds exactly `bar_to − bar_from + 1` bars separated by `|`, no leading or
     trailing bar line, ≤ 64 bars per op;
   - `transpose_bars {voice ("" = every voice), bar_from, bar_to, semitones −12..12, 0 refused}` — notes re-spelled with explicit

   duration_s, events, chords, divergent_bars, display_abc|null, violations[]}` (violations only when `base` is given). Pure; reads

1. **FromTake.** The take's recipe engine is `yue2`; it is not a reference, lossy or transform take; it has a `scores` row whose recipe

2. **Edit.** Parses the parent score, applies `abc.Edit`; violations ⇒ 422 `PLAN_EDIT_INVALID {violations}`; identical bytes ⇒ 422

   cot, base and dialect; `edit_json` = `{ops, rationale}`; a result over 64 KiB ⇒ 422 `PLAN_EDIT_INVALID` rule `too_large`.
3. **Audition** (D-DESK-6). Body `{soundfont?, chords? (default block), tail_s?, gain?}`. The spec hash is sha256 of canonical JSON

## Rollout and risks

1. **Staged API surface unverified** (`pipe.plan()`, the plan's ABC text attribute): pinned by two CPU contract tests before the stage
   registers `plan`; a worker without it answers `KIND_UNAVAILABLE`, which closes the capability automatically (G1 C322.5); the canary
   runs only after the operator opens it.
2. **Irregular YuE2 ABC:** warnings, not errors; fuzzing; agreement tests with `yue2.ParseScore` on real fixture scores; a seed whose
   score does not parse is dropped, the others are kept.
3. **Re-tokenisation** (D-DESK-2): the render follows the auditioned text, not the exact tokens; stated in the UI copy ("rendered from
   this score"); the exact path stays possible later because bundles keep the token files.
4. **Plan-first not cheaper** (D-DESK-5): the UI defaults to 8 seeds, shows the estimate before any spend, and warns on a split; the
   spend-free half is the default entry ("Open in the Desk" from a take).
5. **fluidsynth or soundfont change** (an Alpine bump, a new soundfont): `Verify` answers Inconclusive; audition cache keys include the
   version and the soundfont hash, so stale previews are never served.
6. **Image size** (+~150 MB, the soundfont layer): cached across releases (copied before the binary); the deploy pulls it once.
7. **CPU contention:** auditions take the transform slot and wait at most 30 s; at most one child at a time per process.
8. **Untrusted ABC** from agents: size caps (64 KiB plans, 256 KiB T1), event and voice caps, fuzzing; fluidsynth only ever reads our own
   SMF and the configured soundfont.
9. **Hot spots** (C328): `types_m3.go:116`, `generation/{service.go,types.go,plan.go}`, `lineage/modes.go` `Spec`,
   `library/write.go:505-513`, `backup/snapshot.go`, `cmd_library.go`, `app/{m3.go,m5.go,t1.go}`, `api/api.go`, `canary.go`,
   `Dockerfile`, `ci.yml`, `nav.ts`, `router.ts`, `Track.svelte`, `Batch.svelte`, `New.svelte`, `Patch.svelte`: small appended edits,
   one lane at a time, `make regen` after each rebase.
10. **Deploys** are attended; `metamusic config check` first (deploy-safety rule); the T1b deploy adds one env line.

DESK-A2 (2026-11-20, lane `desk-abc2`): `invariants.go`, `edit.go`, `transpose.go`, `normalise.go`, `check.go` in `internal/score/abc`. As built (the code is the contract where it differs from C352.4-7):
`Violation{Code, Voice, Bar int (-1 = not about one bar), Msg}`; `Op{Op, Voice, BarFrom, BarTo, ABC, Semitones, BPM int}` with JSON names `op, voice, bar_from, bar_to, abc, semitones, bpm`; bars are 0-based and inclusive (as `Section.StartBar`); ops apply in order and each refers to the text its predecessors produced.
`Edit` returns `*EditError{Op, Rule, Msg, Line, Col}` (no output) for a malformed op or an unparsable result (rules `no_ops, too_many_ops, bad_op, bad_voice, bad_range, bad_abc, bad_semitones, bad_tempo, pitch_range, shared_span, no_key, overlap, source_unparsable, result_unparsable, unsupported_feature, transpose_unverified, internal`); invariant violations come back as the list with the output. DESK-S1 maps both to 422 `PLAN_EDIT_INVALID`.
`replace_bars` replaces each bar's content span with its own `|`-separated segment (trimmed), so bar lines, comments, `w:` lines and other voices between the bars stay byte-identical; `abc` must be one line without `%`. A multi-bar rest (`Z4`, bars sharing one span) cannot be addressed: `shared_span`. `abc` is split on `|` outside double quotes; a segment that is a field line (`w:`) or ends in a backslash is `bad_abc`. `transpose_bars` refuses a tune with a body key change (inline `[K:..]` or a second `K:` line) with `unsupported_feature`; a transposition that fails its own post-parse check is `transpose_unverified` (not `internal`). `Normalise` leaves such tunes unchanged.
`transpose_bars` writes an accidental only where the bar's reading state (key signature plus accidentals written so far, by the tune's dialect) differs, or after a tie (whose accidental the parser would inherit); `K:` with `Sharps > 0` spells sharps, otherwise flats, so C major gives `_G` then `=G`. Chord symbols and slash basses are rewritten; the re-parsed result is verified note by note (`internal` rule on a mismatch). A tie from an untouched bar into a transposed one is not repaired.
`set_tempo` rewrites the last header `Q:` line (CRLF kept) or inserts `Q:1/4=<bpm>` before `K:`; `BPM` is an int.
`CheckInvariants` treats a bar as edited when its content or bar-line markup differs, so `sections_changed` accompanies a bar count change and a volta marker repeats `unsupported_feature` for every later bar it leaks into.
`Normalise` returns a copy of the source when nothing diverges, for a standard tune, or if the rewrite would not read back to the same pitches. `Report` has `violations` null without a base, `[]` with one; seconds are rounded to microseconds; `bpm` is quarter notes per minute; `duration_s` comes from `Tune.Score` (repeats expanded, null when the score errors, which also adds an error row). `FuzzEdit` seeds three tunes and ran 40 s clean.

DESK-T1 (2026-11-21, lane `desk-t1b`): `internal/score/smf`, `internal/score/synth`, `dsptest.WriteSF2`, `tools/sf2gen`, `Tools.Fluidsynth`, two `config check` lines. As built (the code is the contract where it differs from C353/C354):
`smf.Write` ends every track at `last_tick + round(tailS x 480 x 1e6 / us)` where `last_tick` is the latest note end, tempo entry or meter entry (so a late tempo entry never follows the End of Track) and `us` is the tempo in force there; tail <= 0 or NaN is 0. A zero-length note is written as one tick, pitches clamp to 0..127, velocity to 1..127, program to 7 bits, channel to 4 bits, names to 128 bytes. Track 0 is named `score`; voice tracks carry the voice name, so the voice ID is not in the file. The tempo map is written as given (an empty map writes no tempo event: the synth default is the same 120 BPM `SecondsAt` assumes).
`synth.Request` has no `Reverb` (D-DESK-8: `-R 0 -C 0` always), so the second `TestSynth_TailRendered` case of C208.5 (`-R 1`) does not exist. `Argv(Request)` is exported and golden (`testdata/argv.golden`). Defaults: rate 48000 (accepted 8000..96000), gain 0.5 (accepted 0..10), timeout `TimeoutFor(0)` = 10 s; the caller passes `TimeoutFor(score seconds)`. `NewFluidsynth(ctx, bin)` probes `--version` once (first line, <= 80 bytes; `ErrUnavailable` for an empty or failing binary). `Render` removes a stale `Out`, runs `mediatool.Run` with `Group: true`, stdout discarded, stderr bounded to 8 KiB, and answers `ErrNoOutput` when the file is missing or empty. `synth.Set` takes `[]synth.Font{Name, Path}` (the layout of `config.Soundfont`, so `synth.Font(sf)` converts it) because C350.2 forbids `internal/score/synth` importing `internal/config`; `NewSet(fonts, *slog.Logger)` keeps configured order, drops duplicate names, and logs `name` and a fixed reason, never a path.
